誰做
我做。出線的願望我親手做成 skill,放上 GitHub,免費、開源、 Claude Code 與 Codex 都能用 —— 下面「成品長這樣」那兩個就是這樣來的。
多久
每 3 天結算一次。倒數就在上面那一格,不是喊爽的。
要幾票
門檻只算別人的票。許願的人自動有一票,但那票不算數 —— 至少要有一個別人也說「我也要」,才有資格出線。
沒出線呢
票會留著,下一輪繼續比 —— 不歸零。而且沒出線不等於沒人做: 想法夠好的我也會挑來做,只是只有出線的那一個是我保證會做的。
做不出來呢
就在那個願望底下寫清楚為什麼(狀態改成「暫不做」)。 不會裝作沒看見,也不會把做不到的東西說成做得到。

寫成這樣比較容易被做出來: ① 講你現在怎麼做這件事,不是講你要什麼功能 ② 講清楚做完長什麼樣(拿到一份表格?一句提醒?) ③ 一個願望只裝一件事,太大的拆成兩個
