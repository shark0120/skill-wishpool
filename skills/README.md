# 成品放這裡

這個資料夾放**已經做出來的 skill**。願望在池子裡被聯署、出線、做完之後,
成品就會放進這裡,首頁的「成品長這樣」也會掛上連結。

一個 skill 就是一個資料夾,裡面至少要有 `SKILL.md`:

```
skills/
└─ ai/
   ├─ SKILL.md          # 觸發條件 + 工作流程,AI 讀這個
   ├─ reference/        # 需要時才載入的細節
   └─ templates/        # 產出用的樣板
```

## 怎麼用

把整個資料夾複製到你的 skills 目錄就好,不用安裝、不用註冊:

```bash
# 全域(所有專案都能用)
cp -r skills/ai ~/.claude/skills/

# 或只給單一專案用
cp -r skills/ai <你的專案>/.claude/skills/
```

然後在對話裡打 `/ai`,或講出 SKILL.md 裡 `description` 寫的那些觸發語。

## 目前有的

| Skill | 一句話 | 做什麼 |
|---|---|---|
| [`ai`](ai/) | 小時制的工作戰役 | 給它一個小時數,它排出時程與任務密度、平行偵查、大量產出、每 N 輪壓縮進度寫進持久狀態,換 session 可以接著跑 |

## 這些是去識別化過的版本

原始的 skill 裡有作者自己的專案代號與本機絕對路徑。放上來之前都換成
`<你的專案>` / `站台 A` 這類通用寫法 —— **機制、紅線、模板一字未改**,
去掉的只是「這是誰的專案」。
