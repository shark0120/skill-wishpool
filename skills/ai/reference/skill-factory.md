# Skill Factory — 戰役內大量產/強化 Skill 規則

由 `/ai` 每輪 FACTORY 階段載入。目標：**可觸發、可執行、不重複、能被口語打到**。

## 何時新建 vs 強化

| 情況 | 動作 |
|---|---|
| 已有 skill 覆蓋同一觸發 | **Edit 舊 SKILL.md**（補步驟/觸發句/驗收） |
| 缺口是新領域且 ≥1 個明確觸發 | **新建** `skills/<name>/SKILL.md` |
| 只有一句空話、無可執行步驟 | **不准建** |
| 與禁區強相關（直接教改 ledger） | **不准建**；可建「檢查/拒絕清單」類 skill |

## 放置位置

| 類型 | 路徑 |
|---|---|
| 某個專案的 production 相關 | `<你的專案>\.claude\skills\<name>\` |
| 通用工具（壓縮、時程、工廠） | `C:\Users\User\.claude\skills\<name>\` |
| 戰役暫存索引 | `.claude/ai-campaign/skills-outbox/<name>.md` 一行鏈接 |

## 檔案最小骨架

```markdown
---
name: "kebab-name"
description: "一句話能力。當使用者說「觸發A」「觸發B」「觸發C」時使用。"
---

# Title

## 觸發
- …

## 禁止
- …

## 步驟
1. …
2. …

## 驗收
- …

## 接線
- 上游/下游 skill 名
```

## description 寫作鐵律

- 必須含 **≥3 個**使用者可能說的口語/slash。
- 必須讓路由系統「看 description 就知道何時用」。
- 禁止空泛：「幫助使用者處理各種問題」。

## 品質門（寫完自檢）

- [ ] 名稱 kebab-case、不與現有目錄撞名
- [ ] 步驟可在無原作者的情況下執行
- [ ] 標明 no-touch / 安全界
- [ ] 有驗收（命令或可見結果）
- [ ] 不複製整份另一 skill；重複則改強化
- [ ] 中文可讀（使用者偏好中文）

## 批量節奏（配合小時）

- 單輪新建 **≤3** 個 skill（防濫造）。
- 同輪應至少 **試跑 1 個** 新/改 skill（最小真實任務或 dry-run 步驟）。
- 每小時結束跑一次 **去重掃描**：同名觸發合併。

## 種子優先序（從高到低）

1. 使用者剛踩過的痛（token、部署、模糊指令）
2. 路由缺口（有口語無 skill）
3. 驗證/壓縮/交接元技能
4. 站點垂直 UI/SEO（安全區）
5. 錦上添花

## 禁止的 skill

- 教如何繞過安全/竊取/外傳 telemetry
- 內嵌真實 secret
- 只 wrap 現有 skill 而無新增步驟（改在舊 skill 加 alias 句）
